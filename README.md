# Pocket Phone

มือถือจำลองเต็มจอสำหรับ SillyTavern — แชท โทร ฟีดโซเชียล กระเป๋าเงิน และอื่น ๆ กับตัวละครในเครื่องของคุณ ทำงานฝั่งเบราว์เซอร์ล้วน ไม่ต้องติดตั้งเซิร์ฟเวอร์เสริม

> **สถานะ:** รุ่นเทสเตอร์ (เบต้า) — ยังพัฒนาต่อเนื่อง เจอบั๊กหรืออยากได้อะไรเพิ่ม แจ้งได้ที่ Issues
>
> **ใหม่ใน 1.2.1:** แก้ Pocket Phone ไม่อัปเดตและ sync frame ค้างบนหน้าจอมือถือ เพิ่ม watchdog สำรองสำหรับ SillyTavern ที่ไม่ส่ง event จบการเจน รีเฟรชแอปที่เปิดอยู่ทุกระบบ และรองรับ API เจนรูปแบบใหม่/เก่าโดยไม่ยิงคำขอซ้ำ
>
> **1.2.0:** Main chat ใช้ system prompt ชั่วคราว + data frame ข้อความธรรมดาที่ถูกอ่านแล้วลบออก ไม่แก้ข้อความผู้ใช้และไม่พึ่ง HTML comment/div ซ่อน พร้อมขยายให้คำตอบเดียวอัปเดตฟีเจอร์มือถือที่เกิดจากเนื้อเรื่องได้ครบขึ้น

---

## ติดตั้ง

1. เปิด SillyTavern → **Extensions** → **Install Extension**
2. วางลิงก์ repo นี้แล้วติดตั้ง
3. รีเฟรชหน้า
4. เปิดใช้งานได้จาก **ปุ่มลอยมุมขวาล่าง** หรือเมนู **wand (Extensions)**

> อัปเดตแล้วแนะนำให้ล้างแคชเบราว์เซอร์ (ดูหัวข้อ [ล้างแคช](#ล้างแคช) ท้ายไฟล์)

## ภาพรวมความสามารถ

Pocket Phone จำลองมือถือหนึ่งเครื่อง มีหลายแอปในตัว ทุกแอปเชื่อมข้อมูลกันและเชื่อมกับเนื้อเรื่องหลักได้ (เปิด/ปิดได้)

### โหมดหนึ่งคำขอ + ซิงค์อัตโนมัติ
- ทุกคำตอบหลักของ SillyTavern มี data frame JSON แบบข้อความธรรมดาในคำตอบเดียวกัน จึงใช้โควตาเท่ากับการโรลปกติ **1 คำขอ** ไม่ได้เรียกโมเดลรอบสอง ระบบอ่านแล้วลบ frame ออกจากทั้งจอและไฟล์แชท
- ไม่ใช้ HTML comment, hidden div หรือ hidden span เป็นช่องทางซิงค์อีกต่อไป จึงไม่พังตาม sanitizer/ตัวจัดรูปแบบ HTML
- ชุดเดียวอัปเดตได้พร้อมกัน: คอนแทกต์ · ข้อความ/เสียง/สติกเกอร์/ตำแหน่ง/ของขวัญ/โพล/ยกเลิกข้อความ · แชทกลุ่ม · สายโทร · ข่าว · โพสต์/โพล · สตอรี่/การตอบ · คอมเมนต์/ตอบกลับ · ไลก์/บันทึก/รีโพสต์/โหวต · เงิน/คำขอเงิน · ผู้ติดตาม · สเตตัส
- ถ้าเนื้อเรื่องพูดถึงข้อความใหม่ในกลุ่ม รอบนั้นสามารถสร้าง unread และข้อความจริงในกลุ่มบนมือถือทันที
- เจนแชทกลุ่มใช้หนึ่งคำขอรวมสำหรับสมาชิกทุกคน แทนการยิง API แยกทีละสมาชิก
- retry อัตโนมัติถูกปิดในโหมดนี้ รวมถึงการอ่านภาพจะลองช่องทางเดียวเท่านั้น
- ทุกเทิร์นมีใบยืนยันผล: สำเร็จ / ไม่มีรายการใหม่ / ไม่พบชุดซิงค์ / รูปแบบไม่ถูกต้อง
- ถ้าโมเดลไม่ส่งชุดซิงค์ ระบบจะแจ้งตรง ๆ และ **ไม่ยิง API ซ้ำ** เพื่อรักษาขีดจำกัดหนึ่งคำขอ

### แอปข้อความ
- เพิ่มตัวละครจาก SillyTavern เข้ามาเป็นรายชื่อคนคุย
- แชทเป็นข้อความจริง กด Enter ส่ง แล้วกดปุ่มเจนให้ตัวละครตอบ พิมพ์รัวหลายข้อความก่อนค่อยให้ตอบก็ได้
- ฟองแชทจับกลุ่ม มีเส้นคั่นเวลา สถานะ "ส่งแล้ว/อ่านแล้ว" และเวลากำกับ
- แท็บรายชื่อ: ยังไม่อ่าน / ปักหมุด / ตัวละคร / NPC เรียงตามที่คุยล่าสุด
- ปัดแถวแชทเพื่อ ปักหมุด · ปิดเสียง · เก็บเข้าคลัง · ลบ
- ปัดฟองข้อความไปขวาเพื่อตอบข้อความนั้น แตะฟองเพื่อ ตอบ · ติดดาว · แก้ไข · แชร์ · เลือกหลายข้อความ · ลบ
- ค้นหาในห้อง และค้นหาข้ามทุกแชทได้
- แนบได้หลายแบบ: รูป · ตำแหน่ง · การ์ดคอนแทกต์ · ข้อความเสียง · โพล (ในกลุ่ม) · โอนเงิน · ของขวัญ · ตั้งเวลาส่ง
- ปรับแต่งแยกต่อคน: พื้นหลังแชท สีฟอง สีตัวอักษร ฟองกระจก ทรงฟอง รูปเป็นพื้นฟอง เสียงเรียกเข้าเฉพาะห้อง
- Persona: ตั้งชื่อ/บุคลิกของตัวละครเฉพาะในมือถือ และเลือก persona ของผู้ใช้ที่บอทคนนั้นรับรู้ (ไม่กระทบข้อมูลจริงใน SillyTavern)

### แชทกลุ่ม
- สร้างกลุ่มเอง เลือกสมาชิก ≥2 คน ตั้งชื่อกลุ่ม
- สวิตช์ "สมาชิกรู้จักกัน" ให้คุยโต้กันได้ หรือปิดให้ต่างคนต่างคุย
- โหมดตอบ: หลายคนต่อการกดเจน หรือทีละคน
- ตั้งคูลดาวน์ระหว่างเจน กันรัว และใส่โน้ต/กติกากลุ่มให้บอทรับรู้ได้
- แสดงชื่อและรูปคนส่งแยกชัดเจน รองรับโหวตโพลในกลุ่ม

### หลายรูท (ซิงค์กับแชทของ SillyTavern)
- ตัวละครหลักหนึ่งคนมีหลายรูทได้ โดยผูกกับ **ไฟล์แชทของ SillyTavern** โดยตรง
- สลับแชทใน SillyTavern → มือถือสลับประวัติตามอัตโนมัติ
- เมนูสามจุดในหน้าแชท → "สลับรูท" เพื่อสั่งสลับจากในมือถือ (รองรับตามความสามารถของ ST เวอร์ชันนั้น)
- แต่ละรูทแยก ประวัติข้อความ · ดาว · unread · ร่าง · ประวัติการโทร ออกจากกัน ไม่ปนข้ามรูท
- ธีมและ persona ยังใช้ร่วมทุกรูท เพราะตัวละครเป็นคนเดิม

### ระบบโทร
- โทรออกหาตัวละคร และตัวละครโทรกลับได้
- พิมพ์คุยในสาย คำพูดทยอยขึ้นทีละประโยค ตัวละครวางสายเองได้เมื่อร่ำลา
- Dynamic Island แสดงสถานะสด: กำลังโทร · กำลังเจนคำตอบในสาย · คุยสายกับใครกี่นาที
- นับเวลาสายจากเวลาจริง กันไม่ให้ส่งข้อความซ้อนตอนอีกฝ่ายกำลังพูด
- ประวัติการโทรแยกตามคนและตามรูท ดูบทสนทนาย้อนหลังและลบได้

### ฟีดโซเชียล (4 แท็บ)
- **หน้าแรก** — สตอรี่ + โพสต์ กดใจ คอมเมนต์ ตอบคอมเมนต์แบบชั้น แชร์เข้าแชท บันทึกโพสต์
- **สำรวจ** — แท็กมาแรง 5 อันดับยอดนิยม ข่าวในโลก และโพสต์แบบกริด
- **กิจกรรม** — การแจ้งเตือนและคำขอติดตาม
- **โปรไฟล์** — โพสต์ของเรา ที่บันทึกไว้ เก็บถาวร Highlights
- กดเจนแล้ว **เลือกได้ว่าให้บอทตัวไหนโพสต์**
- ในโพสต์ กดเจนแล้ว **เลือกบอทที่จะคอมเมนต์ หรือสุ่มพร้อมกำหนดจำนวน**
- ตั้งการมองเห็นต่อโพสต์ได้ (ทุกคน / ผู้ติดตาม / เพื่อนสนิท / เลือกรายคน / ไม่ให้ใครเห็น)

### สตอรี่
- ลงรูปหรือข้อความ อยู่ 24 ชม. เลือกให้ทุกคนหรือเฉพาะเพื่อนสนิทเห็น
- กดหัวใจ ดูคนที่มาดู ตอบสตอรี่กันสองทาง เก็บเข้า Highlight ได้

### กระเป๋าเงิน
- โอน · ขอ · เติม · หัก เงินได้ การโอนขึ้นเป็นการ์ดในแชท
- กราฟรายรับรายจ่าย 7 วัน ตั้งลิมิตต่อวันและสกุลเงินได้
- ตัวละครแต่ละคนมีกระเป๋าของตัวเอง โอนหรือขอจากกันได้

### ประจำเดือน
- ปฏิทินแตะเลือกวัน แตะซ้ำเพื่อบันทึกอาการ อารมณ์ ปริมาณ โน้ต
- คำนวณรอบเฉลี่ยและคาดการณ์รอบถัดไป + ช่วงไข่ตก
- เปิด/ปิดให้บอทรับรู้ได้ ตั้งระดับความใส่ใจ และเลือกได้ว่าให้ใครรู้บ้าง
- **สถานะรอบถูกฉีดเข้า prompt สดทุกครั้งที่บอทตอบ ไม่เขียนลงไฟล์ ค่าจึงถูกต้องเสมอ** ดูข้อความที่บอทเห็นจริงได้ในแท็บความเป็นส่วนตัว

### สติกเกอร์
- สร้างชุดเองด้วยลิงก์รูป + ป้ายชื่อ
- **นำเข้า/ส่งออกชุดเป็นไฟล์ JSON** ชื่อชุดซ้ำจะไม่เขียนทับ แต่ต่อเลขให้อัตโนมัติ
- บอทส่งได้โดยพิมพ์ `[STICKER] ชื่อป้าย`

### สร้าง NPC เอง
- หน้าเพิ่มคนคุย → "สร้าง NPC เอง"
- ตั้งชื่อ บุคลิก และ **เลือกตัวละครหลักเป็นต้นแบบอ้างอิงบุคลิก** (ข้อมูล NPC มักอยู่ในตัวละครหลัก)
- ใช้ตัวอักษรตัวแรกเป็นรูป หรืออัปโหลดรูปปกเองก็ได้
- แก้ไข/ลบได้ ไม่กระทบตัวละครใน SillyTavern

### บันทึกกิจกรรม (หัวใจของรุ่นนี้)
- ทุกอย่างที่คุณทำบนมือถือ (ส่งข้อความ กดใจ โพสต์ โอนเงิน ตั้งสเตตัส ฯลฯ) ถูกเก็บเป็นคิว
- ในการเจนโรลเพลย์ครั้งถัดไป ระบบส่งคิวเป็น **system prompt ชั่วคราว** บอทจึงรับรู้ได้โดยข้อความที่คุณพิมพ์ไม่ถูกแก้ไข และล้างเฉพาะรายการที่ส่งสำเร็จเมื่อคำตอบมาถึง
- ดูคิว ลบทีละรายการ หรือดูตัวอย่างข้อมูลชั่วคราวได้ในตั้งค่า

### ผู้ช่วย
- คู่มือในตัวเครื่อง อธิบายทุกแอปและวิธีใช้แบบกระชับ
- **อ่านได้เฉพาะตอนเปิดแอปนี้เท่านั้น ไม่ถูกส่งเข้า prompt ของบอทหรือเนื้อเรื่องใด ๆ**

### เชื่อมกับเนื้อเรื่องหลัก
- เปิด **"แทรกกิจกรรมเข้าบทหลัก"** → บอทรู้สิ่งที่คุณทำบนมือถือ
- เปิด **"มีผลต่อโรลเพลย์หลัก"** → บทหลักสั่งมือถือได้ (โทร ข้อความ โอนเงิน ติดตาม) ตัวละครใหม่ในเนื้อเรื่องสร้างแชทให้เอง และมือถือยึดบุคลิก/ความสัมพันธ์จากทั้งเธรดของรูทนั้น เพื่อให้โทนตรงกับโรลหลัก ไม่รีเซ็ตเป็นเย็นชา
- Dynamic Island เด้งแจ้งเตือนนอกมือถือได้แม้ปิดแอปอยู่
- รายชื่อคอนแทกต์ กลุ่ม สมาชิกกลุ่ม และโพสต์ล่าสุดจะถูกส่งเป็นรายการย่อให้คำตอบหลักเลือกเป้าหมายได้ถูกต้อง

## เครื่องมือใน Console (สำหรับดีบัก)

เปิด DevTools (มือถือใช้ Eruda) แล้วเรียกได้:

| คำสั่ง | หน้าที่ |
|---|---|
| `PP_DIAG()` | ตรวจว่าเจอ API ของ ST ตัวไหนบ้าง + ข้อมูลปัจจุบัน |
| `PP_PREVIEW_LOG()` | ดูกิจกรรมที่จะเข้า system prompt ชั่วคราว |
| `PP_STRIP_ALL()` | ล้าง HTML block ที่ตกค้างจาก Pocket Phone รุ่นเก่า |
| `PP_STAMP_NOW()` | ตรวจคิวและดูข้อมูลที่จะส่ง โดยไม่แก้ข้อความล่าสุด |
| `window.PP_LOADED` | สถานะโหลด: `ok` = พร้อม, `no-host` = หา mount ไม่เจอ |

## แก้ปัญหาเบื้องต้น

- **เคยใช้รุ่นก่อน 1.2.0 แล้วมี block เก่าค้าง** → เรียก `PP_STRIP_ALL()` หนึ่งครั้งแล้วรีเฟรช รุ่นใหม่จะไม่สร้าง block แบบนั้นอีก
- **กดเจนแล้วไม่ตอบ** → รุ่น 1.2.1 รองรับ API เจนแบบ object arguments ของ SillyTavern รุ่นใหม่แล้ว เรียก `PP_DIAG()` เพื่อตรวจว่าเจอ `generateQuietPrompt` หรือ `generateRaw` ไหม และอ่านข้อความผิดพลาดที่ UI แสดง
- **เห็น `[[POCKET_PHONE_SYNC_V2]]` ค้าง / UI ไม่อัปเดต** → อัปเดตเป็น 1.2.1 แล้วล้างแคช รุ่นนี้มี event hook + watchdog สำรอง อ่าน frame อัปเดตแอปที่เปิดอยู่ และลบ frame จากจอ/ไฟล์แชทอัตโนมัติ
- **สั่งข่าวจากแชทหลัก** → พิมพ์ให้มีคำว่า `ข่าวมือถือ`, `สร้างข่าว`, `เพิ่มข่าว` หรือ `ลงข่าว` ระบบจะบังคับ event ข่าวอย่างน้อย 1 รายการในคำตอบเดียว
- **ขึ้นว่าไม่พบชุดซิงค์** → โมเดลตอบโรลเพลย์ได้แต่ไม่ทำตามรูปแบบซิงค์ ระบบตั้งใจไม่ retry เพื่อไม่ใช้โควตาเพิ่ม ลองตอบเทิร์นถัดไปหรือปิดโหมดหนึ่งคำขอชั่วคราวได้
- **รูปไม่ขึ้น / กลายเป็นกล่องดำ** → พื้นที่เก็บข้อมูลอาจเต็ม ลองใช้รูปเล็กลง
- **สลับรูทจากในมือถือไม่ได้** → ST บางเวอร์ชันไม่รองรับ ให้สลับแชทจาก SillyTavern ตามปกติ ฝั่งมือถือจะตามให้เอง
- **บอทในแชทไม่รู้เรื่องที่โรลหลัก / โทนไม่ตรง** → เปิด "มีผลต่อโรลเพลย์หลัก" ในตั้งค่า

## ล้างแคช

หลังอัปเดตทุกครั้ง แนะนำให้ล้างแคชเบราว์เซอร์:

1. เมนู `:` มุมขวาบนของเบราว์เซอร์ (ถ้าทำเป็นแอปให้กลับเข้า Chrome)
2. การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย
3. ลบข้อมูลการท่องเว็บ → ช่วงเวลา "ทั้งหมด"
4. เลือกเฉพาะ "รูปภาพและไฟล์ที่แคชไว้"
5. เลือกเฉพาะเว็บ SillyTavern แล้วลบ

## ข้อจำกัดที่ควรรู้

- ฝั่งเบราว์เซอร์ล้วน ไม่อ่าน/เขียนไฟล์บนดิสก์ ไม่เก็บ API key
- การกดเจนด้วยตัวเองในแอปมือถือ (ตอบแชท โพสต์ คอมเมนต์ คุยสาย อ่านภาพ) ยังเป็นคำขอ API หนึ่งครั้งต่อการกด แต่ไม่มี retry เพิ่มในโหมดหนึ่งคำขอ
- การซิงค์จากคำตอบหลักไม่เพิ่ม API call แต่ยังขึ้นกับว่าโมเดลส่ง data frame JSON ตามรูปแบบหรือไม่ ใบยืนยันจะแสดงความสำเร็จจริงทุกเทิร์น และ replay protection กันเงิน/ข้อความซ้ำหลังรีโหลด
- การสลับ/ลิสต์แชทจากในมือถือขึ้นกับ API ของ SillyTavern แต่ละเวอร์ชัน
